# Quickstart: Using Settings and Theme Icons

The Settings and Theme icons are located in the Top-Right corner of the main application window.

## Toggling the Theme (Dark/Light mode)

1. Launch the `Media Utility` application.
2. Locate the Theme icon (Sun or Moon) in the top-right corner of the window.
3. Click the icon. The application will immediately switch to the opposite theme.
4. The icon visually changes to reflect the new theme (e.g., Moon for Dark mode, Sun for Light mode).

## Accessing Settings

1. Launch the `Media Utility` application.
2. Locate the Settings icon (Gear) in the top-right corner of the window.
3. Click the icon. The Settings dialog will open, allowing you to customize your preferences (output folder, default codecs, etc.).
