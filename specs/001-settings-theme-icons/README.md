# Phase 001 — Settings & Theme Icons

**Branch**: `001-settings-theme-icons`
**Status**: Draft | **Created**: 2026-03-01

## Goal

Replace the text-based theme toggle and settings link with graphical icons positioned in the top-right corner of the window, making the interface cleaner and more modern.

## What This Phase Delivers

- **Theme toggle icon** — click to switch between Light and Dark mode; icon updates to reflect current state (sun/moon)
- **Settings icon** — click to open the Settings dialog/panel
- Both icons placed in the **top-right corner** of the main window
- Hover **tooltips** on both icons ("Toggle Theme", "Settings")
- Icons scale correctly on high-DPI (4K) displays
- Sufficient contrast in both light and dark themes

## Key Requirements
- `FR-001` Settings access via icon, not text link
- `FR-002` Theme toggle via icon, not text button
- `FR-003` Tooltips on hover for both icons
- `FR-004` Icons positioned top-right corner
- `FR-005` Theme icon reflects active state visually
