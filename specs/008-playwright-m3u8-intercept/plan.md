# Implementation Plan: Playwright HLS Stream Intercept

**Branch**: `008-playwright-m3u8-intercept` | **Date**: 2026-04-17 | **Spec**: `specs/008-playwright-m3u8-intercept/spec.md`

## Summary

Add a headless-browser fallback to the download pipeline: when yt-dlp fails with `no_video`, launch Playwright Chromium, intercept `.m3u8` network requests, resolve the highest-quality HLS variant, forward browser cookies/headers to yt-dlp, and download. New `core/interceptor.py` module; minimal changes to `core/downloader.py` and `gui/tabs/download_section.py`.

## Technical Context

**Language/Version**: Python 3.10+ (3.12 recommended)
**Primary Dependencies**: playwright (Python sync API), yt-dlp (existing), PySide6 (existing)
**Storage**: N/A — no new persistent storage; timeout setting added to `UserSettings`
**Testing**: pytest (existing)
**Target Platform**: Windows, macOS, Linux desktop
**Project Type**: desktop-app
**Performance Goals**: `.m3u8` URL captured and download started within 60 s of URL submission (SC-001)
**Constraints**: Browser session must terminate within `timeout + 5 s` (SC-003); cancel must resolve within 3 s (SC-005); Playwright Chromium binary (~130 MB) must be handled gracefully when not installed
